# Customer Analytics & Machine Learning Project
## BrightMart Retail Analytics: Segmentation, Sales Forecasting & Propensity Modelling

Interactive Streamlit Dashboard & Academic Machine Learning Project.

### Implementation Structure
- `customer_analytics_ml_project.ipynb`: Complete academic Jupyter Notebook containing data preprocessing, EDA, Linear Regression, Decision Tree classification, K-Means clustering, Random Forest ensemble, model evaluation, and business recommendations.
- `app.py`: Professional interactive Streamlit application implementing executive KPIs, interactive charts, sales forecasting, customer clustering, model comparison, and strategic insights.
- `BrightMart_ML_Dataset.csv`: Retail transaction dataset.
- `requirements.txt`: Minimal dependency specification for Streamlit Community Cloud deployment.

### How to Run Dashboard
```bash
pip install -r requirements.txt
streamlit run app.py
```
