## 📊 Project Overview

A complete machine learning analytics project for BrightMart Retail, covering data preparation, EDA, regression, classification, and clustering on a synthetic retail customer dataset of **648 records**.

| Item | Detail |
|------|--------|
| **Dataset** | `BrightMart_ML_Dataset.csv` — 648 customer records, 10 features |
| **Notebook** | `customer_analytics_ml_project.ipynb` — all tasks A–F with visible code & plots |
| **Dashboard** | Live HTML dashboard (no Streamlit, no server needed) |
| **Author** | Aryan Koundal |

## 🧠 ML Models & Results

| Model | Task | Key Metric |
|-------|------|-----------|
| **Linear Regression** | Sales Prediction | R² = 0.8727, MAE = ₹13.10k |
| **Decision Tree** | Campaign Response | Accuracy = 77.69%, F1 = 0.8199 |
| **K-Means (K=3)** | Customer Segmentation | Premium Champions · Aspirational Enthusiasts · Budget Conscious |

👉 **[https://koundal-aryan.github.io/BrightMart-customer-analytics-machine-learning/dashboard.html](https://koundal-aryan.github.io/BrightMart-customer-analytics-machine-learning/dashboard.html)**

### 📂 View Dashboard Locally
Download `dashboard.html` and open in any browser:
```bash
open dashboard.html        # macOS
start dashboard.html       # Windows
xdg-open dashboard.html    # Linux
```

### 📓 Run the Notebook
```bash
pip install -r requirements.txt
jupyter notebook customer_analytics_ml_project.ipynb
```
